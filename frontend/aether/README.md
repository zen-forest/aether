# Aether

Frontend for the Aether application, built with React, TypeScript, Vite, Tailwind CSS, and TanStack Router. UI components are our own, built on Base UI headless primitives and styled with the design tokens described in `design.md`.

## Development

```sh
pnpm install
pnpm dev
```

Additional checks:

```sh
pnpm lint
pnpm build
```

## Project structure

```
src/
  components/        shared, feature-agnostic building blocks (TextBlock, Select, …) on Base UI
  features/          one folder per product area; owns its page and private components
    design-system/   DesignSystemPage + components/ (DocumentCard, sections, ThemeSelect)
    home/            HomePage
  routes/            TanStack file routes; each imports a page from features/ and exports Route
  theme/             color tokens, themes, applyTheme (app-wide infrastructure)
  lib/               framework-agnostic helpers (cn)
```

Rules:

- A feature may import from `components/`, `theme/`, and `lib/`, never from another feature. When two features need the same thing, promote it to `components/`.
- Use the `@/` alias for anything outside the current folder; relative paths only within a feature.
- No `index.ts` barrels: they hide circular imports and defeat per-route code splitting.
- Route files stay thin; page components live in their feature.

## Routing

Routes use TanStack Router's file-based routing:

- `/` — application home
- `/design-system` — design-system reference; renders `design.md` inline, then typography and color

Route definitions live in `src/routes`. `src/routeTree.gen.ts` is generated by the TanStack Router Vite plugin and must not be edited manually.

The design-system route is intentionally independent from the application route so a future authenticated layout can protect product routes without hiding the reference page.
